# 6. Enums and Pattern Matching

Chapter 6 introduces **enums**, which let you create a custom type by listing all possible options, called variants. Enums make it easy to work with different kinds of values. The chapter shows how to define and use enums to represent values and data. It also covers the `Option` enums, which show whether a value exists or is missing.

Next, it explains **pattern matching** using the `match` expression, which lets you handle each enum variant with specific actions. Finally, it describes `if let`,  a simpler way to handle specific enum cases, making your code shorter and clearer.
